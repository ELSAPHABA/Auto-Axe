## ARCHITECTURE / DECISIONS (아키텍처 및 의사결정)
- 약관 [PizzINT Terms of Service 2026-06-25](https://www.pizzint.watch/terms) 재확인: 개인·교육적 이용 및 reasonable rate limiting 공개 API 허용, API 외 스크래핑 금지, 금융/정치/전략 결정 용도 제한. 5분 공식 rate limit을 공급자가 보장하는 것은 아님. DOUGHCON은 참고용이며 금융 판단/자동 주문에 연결하지 않는다.
- 일반 `application/polling.py`는 queued job/retry/catch-up 성격이 있어 PizzINT에서 사용하지 않는다. 5m catalog 등록으로 인해 일반 CADENCE가 자동 선택하지 않도록 source_id 제외. 전용 `application/pizzint_poll.py` / `entrypoints/pizzint_cli.py`.
- `poll_once(dsn, fetch)`: runtime role/DB 검증, session advisory lock `poll:pizzint`, source advisory lock `source:pizzint`로 source grant와 version 확인. `ops.poll_slots`에 DB clock 기반 요청 예약을 HTTP 이전에 독립 commit. 동 DB 내 여러 instance 및 재시작은 예약 후 최소 300초 동안 새 호출하지 않는다. 과거 slot catch-up 없음. daemon은 10초 DB-only wakeup; 실제 주기 300초 이상(일반적으로 300~310초), 공급자 실패에 따라 연장. 한 DB에 하나의 운영 수집 경로 사용.
- TLS/IP pinning 기존 코드 재사용: dedicated Docker target에 stdlib 기반 `autoaxe_scraper/{__init__,policy,transport}.py`만 복사. 일반 브라우저/Scrapling worker는 DB 비밀 없이 격리 정책 유지. 이번 direct API collector는 신뢰된 고정 경로이며 전용 market runtime role만 가지고 브로커/실거래/IdP 비밀 없음. 기존 generic mTLS worker는 배포하지 않음.
- `ProviderHTTPError` status 및 Retry-After 전달, 429/5xx 등은 최소 300초 cooldown (Retry-After가 더 길면 준수), 401/403/7일 초과 retry는 current permission version circuit block. 오류·권한 revoke 후 정상값 조작 금지, 실패 health를 `ops.collector_health`에 기록. 권한을 요청 전/후, 최종 transaction 안에서 동일 version으로 확인하고 원장 commit. DB 오류는 daemon에서 안전한 코드만 출력하고 10초 후 DB 재확인; raw response/DSN/secret 로그 금지.
- 데이터: 검증된 1~5 decimal-string, UTC API timestamp를 event key 및 source_event_at으로 사용, 수신/공개 가능 시각 별도, `Quality.MANUAL_UNVERIFIED`는 기존 비거래/검증되지 않은 참고지표 enum 재사용이며 수동 수집 경로가 아니다. 동일 timestamp와 payload dedup, 같은 시간 수정값 revision, 늦게 도착한 값은 latest를 회귀시키지 않음, metadata={}. 기존 `ingest` + outbox 및 trading prohibition 유지.
- Migration `0006_pizzint_cadence` (parent `0005_phase2_official`) 기존 시장 DB의 `catalog.series.frequency`만 5m으로 갱신, 기존 데이터/매핑 이력은 수정/삭제하지 않음. Fresh catalog/indicator cadence 5m.
- `infra/compose/pizzint.yaml`: 별도 private operational collector, 외부 DB network + egress, 포트 없음, nonroot/read-only/tmpfs/cap drop/memory/pids 제한, init/restart unless-stopped, 기존 fixture stack 기본값 변경 없음. `AUTOAXE_MARKET_RUNTIME_DSN`, `AUTOAXE_MARKET_NETWORK` 필요. 운영 DB 관리자만 source registry 권한 승인; 기존 DB bootstrap은 생산 환경에서 사용하지 않는다.
- 기존 authenticated BFF `/api/v1/dashboard/authorized/market/PENTAGON_PIZZA_PIZZINT`를 재사용하고 collector_status/collector_checked_at을 optional meta로 추가. React DOUGHCON 카드는 참고 지표 및 심리 지표에 표시, 30초 DB-only refetch. 유효한 인증, 원본 권한, 소유자 일치 없으면 값 숨김. API 시각 그대로, 11분 이상 health 미갱신 또는 실패 상태에서는 이전 저장값으로 안내. 일반 fixture UI/고지 유지.
