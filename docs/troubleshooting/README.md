# 개발 트러블슈팅 기록

사용자 지시(2026-11-27): 앞으로 개발 중 발생한 문제 및 해결 과정은 Phase 운영 맥락과 별도의 문서에 상세히 기록한다. Phase log와 상호 링크하고 최초 증상, 재현 명령·환경, 조사 증거, 원인(확인/가설 구분), 기각한 대안, 수정 파일/기술 계약, 재검증 명령과 결과, 남은 위험을 보존한다. 오류 원문 중 비밀 및 개인정보는 제외한다. 실제 문제가 해결되지 않았으면 미해결로 표시한다. 기존 Phase 기록을 대체하지 않는다.

- [Phase 0](phase-00.md): 기존 검증 기록에서 이관한 장애 사례
- [Phase 1](phase-01.md): 데이터 수집·저장 개발 문제
