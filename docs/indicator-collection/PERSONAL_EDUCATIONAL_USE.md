# Auto-Axe 개인·교육·비영리 데이터 이용 정책

## 사용자 확정 용도 (2026-11-27)

- 프로젝트 소유자의 명시적 설명: Auto-Axe는 **개인 학습·교육·연구 목적으로만** 사용하며 영리 목적, 상업적 서비스 운영, 제3자에게 제공하는 서비스, 원본 데이터 판매·공개 재배포가 아니다.
- 프로젝트 자체가 개인용이라는 점은 데이터를 수집·열람·보관하는 사용권의 중요한 사실이다. 다만 공급자 약관에서 명시한 자동화 방식, 접근 횟수, 로그인/유료 영역, 2차 가공, 투자 활용 및 공개 배포 제한은 목적과 별도로 평가한다.
- 공개 GitHub 리포지토리에는 구현 코드·테스트·출처 링크·합성 Fixture만 넣는다. 실제 수집 자료·비밀정보·계정 토큰을 자동 공개하지 않는다.

## 데이터 권한 분리

| 범주 | 기본 처리 |
|---|---|
| 개인 열람 | 관련 사이트가 개인/교육적 열람을 허용하면 가능. 제3자 재배포 권한과 별개 |
| 개인 로컬 보관·분석 | 해당 출처의 이용 조건에서 보관/분석 허용 여부를 확인하고 source_registry에서 fetch/storage 별도 승인 |
| 자동 API 수집 | 제공된 공용 API가 있고 방식·호출량이 허용될 때만 사용. 사용자 수집 목적이 비영리여도 차단/robots/세션 제한을 우회하지 않음 |
| 개인용 인증 화면 | 별도 선택 모드 없음. 지정한 단일 소유자의 OIDC subject와 현재 로그인 계정이 일치하고 source_registry의 fetch/storage가 승인된 경우 개인 조회 허용 |
| 외부 공개·재배포 | 명시적 allow_redistribution=true 없이 금지. 개인 열람과 공개 재배포는 구분 |
| 브로커 주문·자동매매 | 개인/교육용이라는 이유만으로 활성화되지 않으며 기존 위험관리·LIVE 차단 유지 |

|---|---|

| PizzINT | [2026-06-25 약관](https://www.pizzint.watch/terms): 개인·교육 목적의 화면 열람과 합리적 요청 빈도의 공개 API 사용 허용; **API 외 홈페이지 HTML 스크래핑은 금지**. 이미 확인된 [공개 API](https://www.pizzint.watch/api/dashboard-data)로만 접근하도록 고정, 429/403/리디렉션/스키마 오류에서 중단, 자동매매 판단 근거로 사용 금지 |
| CNN·Yahoo·Naver·SEIBro 및 기타 | 비영리 또는 개인용 열람 예외가 있더라도 자동 수집·상시 저장이 명시적으로 허용된다고 추정하지 않음. 각 대상 서비스의 구체 조항과 API 정책에 따라 다르게 판단 |

## 코드 적용 및 범위

- Auto-Axe는 개인·교육·비영리 목적이 고정된 프로젝트다. 사용자가 별도 모드를 선택할 필요가 없으며 화면에 모드 표시를 넣지 않는다. 공통 최하단에 작은 글씨로 **“영리적 목적의 사용을 금지합니다”** 한 문장만 표시한다.
- 서버의 `AUTOAXE_OWNER_SUBJECT_REF`는 개인 조회를 허용할 단일 OIDC `subject_ref`를 가리키는 인가 설정이다(사용자용 모드 아님). 일치하는 소유자 로그인/스코프와 공급자별 `allow_storage`·승인 근거를 모두 확인한다. 소유자가 아니거나 미설정이면 기존 `allow_redistribution` 확인을 유지한다.
- 이전 `AUTOAXE_PRIVATE_EDUCATIONAL_MODE`와 `AUTOAXE_PRIVATE_EDUCATIONAL_OWNER_SUBJECT_REF` 두 변수는 폐기되었다. 개인 조회 여부를 공급자 수집·저장 권한이나 공개 배포 허가로 오인하지 않는다. 여러 사용자 공개 서비스로 목적이 변경되면 별도 설계·재배포 권한 검증이 필요하다.
- `catalog.source_registry`는 외부 제공자별 승인/버전/증거가 기본 unverified이고, 이번 사용자 설명이 특정 공급자의 약관을 자동으로 approved로 변경하지 않는다.
- PizzINT의 운영 스케줄러는 source_registry에서 **DOUGHCON 공개 API에 한정해** 승인된 경우에만 허용한다. 고정 호스트·URL·TLS/DNS·응답 크기/타입을 검사하고 단계(1~5)와 최소 검증 정보만 저장한다. 5분 기본 주기, 429 Retry-After 및 차단 존중, 금융 판단·자동 주문 금지. 원본 JSON 및 다른 지표는 보관하지 않는다. 별도 [운영 컨테이너](../../infra/compose/README.md#pizzint-doughcon-collector)는 실제 DB/인증 환경 설정 후 기동한다.

## 검증 상태

- 본 문서는 프로젝트의 이용 범위를 사용자 요청대로 확정하고, 개인 열람 vs 재배포 권한을 구분하기 위한 정책 기록이다. 법률상 모든 사이트의 모든 수집 방식이 일률적으로 합법이라는 판단은 아니다.
- 실제 외부 서비스 호출이나 운영 Keycloak/mTLS 테스트 없이 Mock/Fixture와 제한된 개발환경에서 검증한 내용은 별도 Phase 2 후속 로그에 기록한다.
