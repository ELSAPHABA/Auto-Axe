# Auto-Axe 프론트엔드 디자인 명세 — Live3x(레버라이브) 레퍼런스

> 분석일: 2026-11-24 · 참조: [live3x.com](https://live3x.com/), [SOXL 상세 화면](https://live3x.com/soxl). 실제 브라우저 렌더링, 공개 화면의 DOM 및 computed style을 조사했다. **관측**은 원본에서 확인한 사실, **적용 명세**는 Auto-Axe에 구현할 제안이다. 원본 코드·브랜드·로고·이미지의 복제는 범위에 포함하지 않는다.

## 1. 디자인 방향

### 1.1 관측

레버라이브는 마케팅 랜딩 페이지가 아니라 **정보 밀도 높은 금융 모니터링 대시보드**다. 어두운 중성 배경, 낮은 대비의 패널, 녹색 활성 상태, 한국형 상승 빨강/하락 파랑을 사용한다. 큰 가격 숫자가 시선의 중심이며, 종목별 미니 차트를 카드 배경에 배치해 한눈에 추세를 파악할 수 있다. 장식보다 데이터가 우선이고, 상단 탭을 제외하면 좌측 사이드바 없이 가로 공간을 적극 활용한다.

### 1.2 Auto-Axe 적용 원칙

- 전체적으로 Live3x의 **가로형 내비게이션 + 고밀도 카드 그리드 + 상세 차트 + 보조 지표**라는 구조를 채택한다.
- Auto-Axe의 독립적인 워드마크·아이콘을 사용한다. 원본 서비스인 것처럼 표시하지 않는다.
- 홈에서 지표 개요, 상세 화면에서 분석과 원본 데이터 정의를 제공한다.
- 시장 가격과 재무·경제 지표의 주기를 혼동하지 않도록 각 패널에 출처·단위·기준시각·신선도 상태를 표시한다.
- 주문·전략 UI는 별도 기능 명세가 확정되기 전까지 디자인의 확장 대상으로만 남긴다.

## 2. 원본 화면 분석

### 2.1 홈 레이아웃

관측 환경: 데스크톱, DOM 콘텐츠 폭 1210 CSS px, viewport 내부 폭 1225 CSS px(스크롤바 포함). 스크린샷 표시 확대율과 CSS px를 구별한다.

- 헤더: 좌측 브랜드, 설명; 우측 로그인, 공지·가격 알림, 테마, 초 단위 KST 시계. 높이 약 62px.
- 콘텐츠: 좌우 padding 30px, 상단 7px, 하단 30px. 실제 측정 폭 1150px.
- 분류 탭: 전체/해외/국내/코인/원자재/야선/즐겨찾기, 선택 탭 녹색 텍스트와 하단 선. 우측 검색·정렬.
- 종목 정렬 옵션: 기본순, 상승률순, 하락률순. 별도 롱·숏 비중 토글.
- 그룹 헤더: 수신 상태, 제공 상품 정보, 갱신 카운트다운, 새로고침, 개수, 공유·스크린샷 복사.
- 원본의 시세 카드와 시장 온도계는 관측 폭에서 각각 4열이다. 시세 카드 그리드 gap 9px, 온도계 gap 12px.
- 하단에는 가격·등락률 기준 설명과 실시간 이벤트 목록이 있다. 원본의 국내 신용융자·예탁금·미수금·선물예수금·한강 수온 등은 **관측 사실**이며 Auto-Axe 신규 수집 대상 확정을 의미하지 않는다.

### 2.2 시세 카드

| 요소 | 원본 관측 |
|---|---|
| 카드 크기 | 약 281 × 164 CSS px (4열, 1210px 콘텐츠 폭에서) |
| 표면 | #171C25 기본, 12px radius, 배경 차트 및 일부 상품별 틴트 |
| 내부 padding | 상 14px, 좌우 16px, 하 12px |
| 첫 줄 | 종목 코드/이름, 장 상태 칩, 레버리지 칩, 우측 즐겨찾기 별 |
| 둘째 줄 | 상품의 설명 |
| 주요 값 | 가격(23px, weight 650) + 작은 통화 단위 |
| 등락률 | 13px, weight 650; 정규장 마감 대비/전일 대비/24h 기준 문구 |
| 보조 값 | 거래대금, 소스와 단위(카드·그룹에 배치) |
| 스파크라인 | 카드 전체 폭 뒤에 SVG 라인/면적, 최근 24h 5분봉 종가, 라인 opacity 0.48·SVG opacity 0.65 (관측 카드) |
| 하단 | 최근 24시간 캡션 |
| 동작 | 카드 링크로 상세 이동, 별은 독립 즐겨찾기 버튼 |

중요: 원본에서 롱·인버스 상품의 배경 틴트와 등락 색상은 동일 규칙이 아닐 수 있다. 상품 종류는 별도 칩으로, 실제 상승·하락은 등락률과 차트 색으로 구별한다. SVG에는 접근 가능한 차트 설명이 있다.

### 2.3 시장 온도계

관측한 원본 섹션에는 빚투, 투자자예탁금, 미수금, 선물예수금, 미국 공포·탐욕, VIX, DRAM 가격, 한강물 온도가 표시된다. 대표 카드 약 279 × 360px, padding 17px 16px 12px, radius 12px. 지표명, 최신 값, 단위, 전 관측일 변화, 기간 선택, 큰 시계열 차트, 하단 공표일 순이다.

- 기간 버튼: 1개월/3개월/1년/3년/전체(지표별 차이 있음). 활성 기간은 녹색 텍스트·옅은 녹색 배경.
- 차트: 독립 시리즈 색상(녹색·보라·주황·청록 등), 얇은 수평 격자, 우측 Y축 수치, 하단 날짜, 마지막 값 컬러 라벨.
- DRAM 카드: 상품 선택 드롭다운(DDR5 16GB, DDR5 32GB, DDR4 16GB 관측). Auto-Axe는 현재 명세의 두 DDR5 모듈만 표시한다.
- 공포·탐욕: 점수/100과 상태 문구, 변화량. VIX는 pt 단위.
- 시세 카드의 짧은 스파크라인과 달리 이 영역은 충분한 차트 높이와 축을 제공한다.

### 2.4 상세 페이지

[SOXL 실제 화면](https://live3x.com/soxl)에서 확인한 순서:

1. 뒤로가기 + 공통 헤더.
2. 화면 상단 출처 안내: Binance 추종 상품이며 실제 미국 주식·ETF 시세와 다르다는 문구.
3. 종목명, 장 상태, 레버리지, 설명, 현재 가격과 통화, 등락률 및 비교 기준 가격·날짜.
4. 수신 상태와 시각, 24h 거래대금, 평소 대비 거래대금. 공유·캡처·즐겨찾기·알림 버튼.
5. PRICE ACTION 차트 패널: 캔들/라인 전환, 범위 초기화, 전체화면, 1분/5분/15분/1시간/4시간/1일 봉 간격, OHLC.
6. MDD·RSI 보조지표(원본 최근 10년 일봉). 이 두 지표는 현재 Auto-Axe 기능 명세의 확정 지표가 아니므로 향후 확장 후보.
7. 구성종목 등락 영역: 지원 개수, 전체/상승/하락 필터, 검색, 기본/비중/상승/하락/이름순 정렬, 카드/표 전환, 각 종목의 비중·가격·등락률.
8. 하단 데이터 안내.

상세는 홈보다 좁은 중앙 컨테이너를 사용하며, 관측 화면에서 약 890 CSS px 폭(스크린샷 비례 측정). 큰 가격과 차트에 시선을 집중시킨다. 구성종목 수급 데이터 수집 기능은 별도 요구사항 확정 대상이다.

### 3.2 Auto-Axe 적용 토큰 (권장)

```css
:root {
  --bg: #0e1117;
  --surface: #171c25;
  --border: #2a3342;
  --text: #e3e8ef;
  --muted: #96a3b7;
  --accent: #78ca65;
  --positive: #ff6b80;
  --negative: #70a5ff;
  --neutral: #96a3b7;
  --warning: #e7bd68; /* 제안 */
  --radius-card: 12px;
  --radius-control: 8px;
  --grid-gap: 10px;
  --page-padding: 30px;
  font-family: Inter, "Noto Sans KR", -apple-system,
               BlinkMacSystemFont, sans-serif;
}
[data-theme="light"] {
  /* Auto-Axe 독립 라이트 테마 제안 — 원본 실측값 아님 */
  --bg: #f5f7fa;
  --surface: #ffffff;
  --border: #dce2ea;
  --text: #17212e;
  --muted: #536477;
  --accent: #327a36;
  --positive: #c42b49;
  --negative: #235fc3;
  --neutral: #536477;
  --warning: #855900;
}
```

상승=빨강, 하락=파랑의 한국형 관례를 기본으로 유지한다. 수익률뿐 아니라 변동 방향은 +/- 및 텍스트를 함께 표기한다. 적색이 반드시 위험이나 오류라는 의미는 아니며 경고·데이터 품질 상태는 별도 상태 토큰/아이콘으로 정의한다. 선택 강조는 녹색, 차트별 독립 시리즈는 구별 가능한 색상을 사용한다.

### 3.3 타이포그래피 및 간격

원본 글꼴 stack: Inter, Noto Sans KR, -apple-system, BlinkMacSystemFont, sans-serif. 본문 기본 weight 450, 제목과 가격은 650. 원본 1210px 환경에서 종목 코드 14px, 가격 23px, 등락률 13px, 종목 설명 9px, 거래대금 8px, 미니 차트 캡션 6px를 확인했다. 다만 작은 글자는 **그대로 복제하지 않고** 읽기 쉬운 다음 기준을 적용한다.

| 요소 | Auto-Axe 권장 크기 |
|---|---|
| 일반 본문·탭 | 13–14px |
| 종목명 / 카드 제목 | 14–16px, 600–650 |
| 시세 카드 주요 숫자 | 24–28px, 650 |
| 상세 주요 가격 | 40–48px, 650–700 |
| 등락률 | 13–14px, 600–650 |
| 단위·기준시각·부가 설명 | 11–12px |
| 섹션 제목 | 15–18px, 600–650 |
| 축·캡션 | 11–12px |

금액·시각에 `font-variant-numeric: tabular-nums`를 적용하여 값 갱신 시 자리 이동을 줄인다. 4px 단위 여백(4/8/12/16/24/32), 카드 radius 12px, 패널 경계 1px 이하, 과한 그림자 및 그라디언트 금지.

| FundamentalsPanel | 후행/예상 PER, PBR, ROE, 조회·재무 기준시점 및 결측 상태 |
| RangePanel | 5/10/20거래일 High·Low, 확정 일봉 또는 직전 N봉 기준 표시 |
| EventTable | 예정/발표 시간, 종류, 실제/이전/예상, 상태, 출처, DTE |
| SourceStatus | provider, observedAt, receivedAt, permissionStatus, qualityStatus |

공유·이미지 복사·가격 알림·카드/표 전환은 원본에서 확인한 UI 패턴이며 Auto-Axe에서 실제 기능 구현은 별도 확정·검증해야 한다. 기능하지 않는 버튼은 배포하지 않는다.

### 4.2 시세 카드와 상세 차트 규칙

- **시세 카드:** 데이터 타입/거래소를 명시하고 가격과 등락률을 가장 크게 표시. 배경 SVG 스파크라인은 원본 24h 5분봉 패턴을 참고하되 실제 확보된 이력만 사용한다.
- **데이터 기준:** Binance BTCUSDT는 Spot, 금속·원유는 USDT 영구선물, Yahoo 주식은 실제 종목의 제공 시세, MEXC Nasdaq 연동은 별도 파생상품. 통화·상품·비교기준을 생략하지 않는다.
- **롱숏:** 전체 계정, 상위 계정, 상위 포지션, Taker 거래량을 각각 선택. Taker 비율과 포지션 비율은 혼동하지 않으며 최소 5분 집계임을 표시한다.
- **상세:** 캔들/라인, 봉 간격, 현재 OHLC, 커서 툴팁, 범위 초기화. 지원 데이터 범위 내에서만 버튼 활성화. SMA/EMA overlay와 High/Low 기준선을 옵션으로 표시한다.
- **누적 거래량:** 정수 주 단위 최신 당일 누적량을 표시하되 source timestamp와 로컬 1초 sample timestamp를 분리한다. 분봉 거래량 및 거래대금과 같은 지표명으로 합치지 않는다.
- **시장 지표 차트:** 실제 주기(주간/일별/5분 등)에 맞는 기간 범위와 axis. 결측은 선을 끊고 과거값을 새 값으로 위장하지 않는다.
- **테이블:** 숫자는 우측 정렬, 이름과 출처는 좌측 정렬, 정렬 상태는 헤더에서 명확히 표시. 모바일에서는 핵심 열 우선 및 필요 시 수평 스크롤.

## 5. 반응형 및 사용자 경험

원본의 실제 모바일 레이아웃 및 breakpoint는 미검증이므로 아래는 **Auto-Axe 구현 제안**이다.

| Viewport | 시세 카드 | 지표 카드 | 페이지 padding |
|---|---|---|---|
| ≥1200px | 4열 | 4열 | 30px |
| 900–1199px | 3열 | 2~3열 | 24px |
| 600–899px | 2열 | 2열 | 16px |
| <600px | 1~2열(최소 160px 및 실제 문구 폭 검증) | 1열 | 12px |

상세 컨테이너는 최대 960~1120px로 제한하고 좁은 화면에서 100% 폭으로 확장한다. 헤더 보조 설명을 축소하고 분류 탭을 가로 스크롤로 제공한다. 터치 타깃 최소 44px 권장, 키보드 포커스 표시, aria-label, 색상 외 방향 기호, 차트의 텍스트 요약 제공.

### 5.1 상태 및 갱신

| 상태 | 화면 표현 |
|---|---|
| fresh | 최신 수신 값·기준시각, 연결 상태 표시. 무지연을 단정하지 않음 |
| no_update | 최신 기존 값 유지 + 새 메시지 없음 |
| stale | 기존 값과 마지막 원본시각 + 지연 표시 |
| disconnected | 연결 끊김, 재연결 진행 상태 |
| no_data / missing | 대시 또는 데이터 없음, 0으로 대체 금지 |
| permission_required | 자동수집 비활성, 권한 확인 필요 |
| manual | 수동 입력, 입력/기준 시각 |
| session_reset | 누적량 리셋·거래일 변경 |
| loading | 카드 크기를 유지하는 skeleton |

1초마다 전체 페이지를 재렌더링하지 않는다. 수신 데이터와 화면 갱신을 분리해 필요한 카드만 갱신하며, 브라우저 숨김·오프라인에서 불필요한 UI 작업을 줄인다. 원본 관측 주기보다 짧게 새 데이터를 보여주는 허위 애니메이션을 사용하지 않는다. 카드 새로고침은 서버 캐시 및 호출 제한을 준수하며 무제한 외부 요청을 발생시키지 않는다.

## 6. 구현 및 검수

- 프론트엔드 프레임워크, 차트 라이브러리, CSS 기술은 확정하지 않는다. SVG 스파크라인 및 Canvas 기반 시계열 차트는 구현 후보이며 원본 라이브러리 사용 여부는 단정하지 않는다.
- 1차: 토큰·헤더·탭·카드·그리드·테마·샘플 데이터 기반 정적 프로토타입.
- 2차: 기존 기능 명세의 데이터 계약과 연결, 누락/지연/권한 상태 및 실제 시계열.
- 3차: 종목 상세 차트, 기술지표, 이벤트·거시 지표, 수집 상태.
- 4차: 반응형·키보드·대비·렌더링 성능 검수. 360/390/768/1024/1440px에서 잘림·오버플로 확인.
- 검수: 가격/단위/원본 시각 일관성, 상승/하락 색상과 텍스트, 탭 및 정렬, 1Hz 업데이트의 안정성, 차트 결측 처리, 라이트/다크 대비(일반 텍스트 WCAG AA 4.5:1 목표), 주문 관련 기능 비활성 상태 확인.

## 7. 근거 및 범위

- [원본 홈](https://live3x.com/): 화면 및 DOM, 카드/그리드 computed style, 테마 메뉴, 온도계 영역 확인.
- [원본 SOXL 상세](https://live3x.com/soxl): 출처 고지, 상세 헤더, 차트 조작부, 구성종목 필터·표 전환, 보조지표 확인.
