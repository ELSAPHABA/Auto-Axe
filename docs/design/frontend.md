# Auto-Axe 프론트엔드 디자인 명세 — Live3x(레버라이브) 레퍼런스

> 분석일: 2026-11-24 · 참조: [live3x.com](https://live3x.com/), [SOXL 상세 화면](https://live3x.com/soxl). 실제 브라우저 렌더링, 공개 화면의 DOM 및 computed style을 조사했다. **관측**은 원본에서 확인한 사실, **적용 명세**는 Auto-Axe에 구현할 제안이다. 원본 코드·브랜드·로고·이미지의 복제는 범위에 포함하지 않는다.

## 1. 디자인 방향

### 1.1 관측

레버라이브는 마케팅 랜딩 페이지가 아니라 **정보 밀도 높은 금융 모니터링 대시보드**다. 어두운 중성 배경, 낮은 대비의 패널, 녹색 활성 상태, 한국형 상승 빨강/하락 파랑을 사용한다. 큰 가격 숫자가 시선의 중심이며, 종목별 미니 차트를 카드 배경에 배치해 한눈에 추세를 파악할 수 있다. 장식보다 데이터가 우선이고, 상단 탭을 제외하면 좌측 사이드바 없이 가로 공간을 적극 활용한다.

### 1.2 Auto-Axe 적용 원칙

- 전체적으로 Live3x의 **가로형 내비게이션 + 고밀도 카드 그리드 + 상세 차트 + 보조 지표**라는 구조를 채택한다.
- Auto-Axe의 독립적인 워드마크·아이콘을 사용한다. 원본 서비스인 것처럼 표시하지 않는다.
- 홈에서 지표 개요, 상세 화면에서 분석과 원본 데이터 정의를 제공한다.
- 시장 가격과 재무·경제 지표의 주기를 혼동하지 않도록 각 패널에 출처·단위·기준시각·신선도 상태를 표시한다.
- 매수·매도 Workflow UI는 노드 편집 방식의 확정 요구사항을 따른다. 실주문·계좌 연동 상세는 추가 확정 대상으로 남긴다.

## 2. 원본 화면 분석

### 2.1 홈 레이아웃

관측 환경: 데스크톱, DOM 콘텐츠 폭 1210 CSS px, viewport 내부 폭 1225 CSS px(스크롤바 포함). 스크린샷 표시 확대율과 CSS px를 구별한다.

- 헤더: 좌측 브랜드, 설명; 우측 로그인, 공지·가격 알림, 테마, 초 단위 KST 시계. 높이 약 62px.
- 콘텐츠: 좌우 padding 30px, 상단 7px, 하단 30px. 실제 측정 폭 1150px.
- 분류 탭: 전체/해외/국내/코인/원자재/야선/즐겨찾기, 선택 탭 녹색 텍스트와 하단 선. 우측 검색·정렬.
- 종목 정렬 옵션: 기본순, 상승률순, 하락률순. 별도 롱·숏 비중 토글 및 ON 상태의 집계 기준 선택 드롭다운. 상세 규격은 §4.3 참조.
- 그룹 헤더: 수신 상태, 제공 상품 정보, 갱신 카운트다운, 새로고침, 개수, 공유·스크린샷 복사.
- 원본의 시세 카드와 시장 온도계는 관측 폭에서 각각 4열이다. 시세 카드 그리드 gap 9px, 온도계 gap 12px.
- 하단에는 가격·등락률 기준 설명과 실시간 이벤트 목록이 있다. 원본의 국내 신용융자·예탁금·미수금·선물예수금·한강 수온 등은 **관측 사실**이며 Auto-Axe 신규 수집 대상 확정을 의미하지 않는다.

### 2.2 시세 카드

| 요소 | 원본 관측 |

| 카드 크기 | 약 281 × 164 CSS px (4열, 1210px 콘텐츠 폭에서) |
| 표면 | #171C25 기본, 12px radius, 배경 차트 및 일부 상품별 틴트 |
| 내부 padding | 상 14px, 좌우 16px, 하 12px |
| 첫 줄 | 종목 코드/이름, 장 상태 칩, 레버리지 칩, 우측 즐겨찾기 별 |
| 둘째 줄 | 상품의 설명 |
| 주요 값 | 가격(23px, weight 650) + 작은 통화 단위 |
| 등락률 | 13px, weight 650; 정규장 마감 대비/전일 대비/24h 기준 문구 |
| 보조 값 | 거래대금, 소스와 단위(카드·그룹에 배치) |
| 스파크라인 | 카드 전체 폭 뒤에 SVG 라인/면적, 최근 24h 5분봉 종가, 라인 opacity 0.48·SVG opacity 0.65 (관측 카드) |

중요: 원본에서 롱·인버스 상품의 배경 틴트와 등락 색상은 동일 규칙이 아닐 수 있다. 상품 종류는 별도 칩으로, 실제 상승·하락은 등락률과 차트 색으로 구별한다. SVG에는 접근 가능한 차트 설명이 있다.

### 2.3 시장 온도계

관측한 원본 섹션에는 빚투, 투자자예탁금, 미수금, 선물예수금, 미국 공포·탐욕, VIX, DRAM 가격, 한강물 온도가 표시된다. 대표 카드 약 279 × 360px, padding 17px 16px 12px, radius 12px. 지표명, 최신 값, 단위, 전 관측일 변화, 기간 선택, 큰 시계열 차트, 하단 공표일 순이다.

- 기간 버튼: 1개월/3개월/1년/3년/전체(지표별 차이 있음). 활성 기간은 녹색 텍스트·옅은 녹색 배경.
- 차트: 독립 시리즈 색상(녹색·보라·주황·청록 등), 얇은 수평 격자, 우측 Y축 수치, 하단 날짜, 마지막 값 컬러 라벨.
- DRAM 카드: 상품 선택 드롭다운(DDR5 16GB, DDR5 32GB, DDR4 16GB 관측). Auto-Axe는 현재 명세의 두 DDR5 모듈만 표시한다.
- 공포·탐욕: 점수/100과 상태 문구, 변화량. VIX는 pt 단위.
- 시세 카드의 짧은 스파크라인과 달리 이 영역은 충분한 차트 높이와 축을 제공한다.

### 2.4 상세 페이지

[SOXL 실제 화면](https://live3x.com/soxl)에서 확인한 순서:

1. 뒤로가기 + 공통 헤더.
2. 화면 상단 출처 안내: Binance 추종 상품이며 실제 미국 주식·ETF 시세와 다르다는 문구.
3. 종목명, 장 상태, 레버리지, 설명, 현재 가격과 통화, 등락률 및 비교 기준 가격·날짜.
4. 수신 상태와 시각, 24h 거래대금, 평소 대비 거래대금. 공유·캡처·즐겨찾기·알림 버튼.
5. PRICE ACTION 차트 패널: 캔들/라인 전환, 범위 초기화, 전체화면, 1분/5분/15분/1시간/4시간/1일 봉 간격, OHLC.
6. MDD·RSI 보조지표(원본 최근 10년 일봉). Auto-Axe는 RSI 트리거 및 낙폭 성과 리포트를 승인 기능에 포함한다. 원본과 동일한 10년 화면은 별도 데이터 가용성 검증이 필요하다.
7. 구성종목 등락 영역: 지원 개수, 전체/상승/하락 필터, 검색, 기본/비중/상승/하락/이름순 정렬, 카드/표 전환, 각 종목의 비중·가격·등락률.
8. 하단 데이터 안내.

상세는 홈보다 좁은 중앙 컨테이너를 사용하며, 관측 화면에서 약 890 CSS px 폭(스크린샷 비례 측정). 큰 가격과 차트에 시선을 집중시킨다. 구성종목 수급 데이터 수집 기능은 별도 요구사항 확정 대상이다.

### 2.5 롱·숏 비중 UI (사용자 제공 Live3x 화면 추가 분석)

근거: 사용자 제공 이미지 2장(상세 페이지 비율 패널 및 시세 카드 ON 상태). 아래 비율·가격·시각은 **이미지 속 예시값**으로서 현재 시장 데이터가 아니다. 스크린샷의 픽셀 크기는 브라우저 CSS px로 단정하지 않으며, 실제 원본 드롭다운 전체 옵션 및 토글 저장 동작은 확인하지 않았다.

**홈 ON 상태 (첨부 두 번째 이미지)**

- 분류 탭 아래 한 줄: `롱·숏 비중` → 녹색 트랙과 흰색 원형 손잡이 → 녹색 `ON` → `집계 기준` → 어두운 드롭다운 `전체 계정` + 아래 방향 chevron. ON/OFF 문구를 스위치 옆에 표기한다.
- 카드 본래 영역(종목명/장 상태/레버리지/설명/가격/등락률/거래대금 및 배경 스파크라인)을 유지한 채, 거래대금 아래 얇은 구분선을 추가한다.
- 추가 영역: 첫 줄 좌측 `롱·숏`, 우측 현재 선택된 집계 기준; 둘째 줄 좌측 붉은색 `롱 75.8%`, 우측 파란색 `24.2% 숏` 등; 다음 줄 단일 100% 가로 누적 비율 막대; 하단 회색 `11.24. 15:00 집계`와 기존 차트 기간 캡션.
- SOXL 예시 75.8%/24.2%, SOXS 예시 56.1%/43.9%. 토글 ON 시 카드가 세로로 확장되며 폭과 그리드 구성은 유지된다. 서로 다른 카드의 비율 막대와 시간 영역을 같은 높이에 정렬한다.
- 이전 브라우저 관측에서 OFF 상태는 별도 집계 기준 선택과 비율 영역이 보이지 않았다.

**종목 상세 페이지 (첨부 첫 번째 이미지)**

- 전체 폭의 둥근 패널 안에 제목 `롱·숏 비중` 및 부제 `SOXL · USDT 추종 선물 · 1시간 집계`. 우측에 공유, 스크린샷 복사, `5분마다 확인`, 새로고침 아이콘을 배치한다.
- 패널 본문은 세 개의 동등한 열: `전체 계정`, `상위 20% · 계정 수`, `상위 20% · 포지션 규모`. 각 제목 옆 정보 아이콘을 두고 정의를 설명한다.
- 각 열은 붉은 롱 수치(왼쪽), 파란 숏 수치(오른쪽), 끊기지 않는 100% 비율 막대, 원본 집계 시각 순서다. 이미지의 예시는 각각 75.8/24.2, 79.2/20.8, 78.2/21.8이다.
- 상세 패널의 **1시간 집계**와 **5분마다 확인**은 서로 다른 개념(집계 기간과 조회 주기)이다.
- 바로 아래 별도 패널은 `마크 가격`, `지수 가격`, `펀딩 비율`, `다음 펀딩`의 네 열 요약으로 구성된다. 이 네 항목은 원본 UI에서 확인한 디자인 참고 사항으로, 기존 Auto-Axe 수집 요구사항에는 명시적으로 확정되어 있지 않다. 별도 소스·상품·계산·권한 검증을 거쳐 기능 명세에 등록하기 전에는 실제 데이터 수집 기능을 구현 완료로 간주하거나 허위 수치를 표시하지 않는다.

### 4.2 시세 카드와 상세 차트 규칙

- **시세 카드:** 데이터 타입/거래소를 명시하고 가격과 등락률을 가장 크게 표시. 배경 SVG 스파크라인은 원본 24h 5분봉 패턴을 참고하되 실제 확보된 이력만 사용한다.
- **데이터 기준:** Binance BTCUSDT는 Spot, 금속·원유는 USDT 영구선물, Yahoo 주식은 실제 종목의 제공 시세, MEXC Nasdaq 연동은 별도 파생상품. 통화·상품·비교기준을 생략하지 않는다.
- **롱숏:** 전체 계정, 상위 계정, 상위 포지션, Taker 거래량을 각각 선택. Taker 비율과 포지션 비율은 혼동하지 않으며 최소 5분 집계임을 표시한다.
- **상세:** 캔들/라인, 봉 간격, 현재 OHLC, 커서 툴팁, 범위 초기화. 지원 데이터 범위 내에서만 버튼 활성화. SMA/EMA overlay와 High/Low 기준선을 옵션으로 표시한다.
- **누적 거래량:** 정수 주 단위 최신 당일 누적량을 표시하되 source timestamp와 로컬 1초 sample timestamp를 분리한다. 분봉 거래량 및 거래대금과 같은 지표명으로 합치지 않는다.
- **시장 지표 차트:** 실제 주기(주간/일별/5분 등)에 맞는 기간 범위와 axis. 결측은 선을 끊고 과거값을 새 값으로 위장하지 않는다.
- **테이블:** 숫자는 우측 정렬, 이름과 출처는 좌측 정렬, 정렬 상태는 헤더에서 명확히 표시. 모바일에서는 핵심 열 우선 및 필요 시 수평 스크롤.

Taker 선택 시 카드 소제목은 `매수·매도`로 바꾸고 좌우 레이블도 `매수`, `매도`로 표시한다. `상위 20%` 표기는 해당 공급자의 실제 정의와 일치할 때만 사용한다.

| 요소 | Auto-Axe 적용값 |

| 막대 | width 100%, 홈 높이 6–8px, 상세 높이 8–12px |

| 왼쪽 구간 | 롱(또는 Taker 매수), --ratio-long = #FF6B80 |
| 오른쪽 구간 | 숏(또는 Taker 매도), --ratio-short = #70A5FF |

| 제목/레이블 | 홈 11–12px / 상세 14–16px; 좌우 끝 정렬 |

- 데스크톱은 3열, 좁은 화면에서는 2열 또는 1열로 순차 배치. 홈 전역 토글이 OFF라도 상세의 독립적인 비율 패널은 지원 상품에서 제공한다.
- 각 정보 아이콘은 통계 정의와 단위, 집계 기간을 설명한다. 상위 계정과 상위 포지션의 분모 차이를 명시한다.
- Taker 매수·매도 거래량은 세 개 롱·숏 통계와 별도의 패널/행으로 배치하여 정의를 혼용하지 않는다.
- 원본의 1시간 집계 표시를 참고하되 Auto-Axe의 기본 집계는 **5분**, 선택 기간은 공급자 지원 범위(5m, 15m, 30m, 1h, 2h, 4h, 6h, 12h, 1d). 예를 들어 1시간을 선택하고 5분마다 확인하더라도 실제 1시간 자료가 새로 생성되기 전까지 동일한 원본 시각을 유지한다.
- 공유·캡처는 구현 시 패널 전체와 출처·집계 시각을 포함한다. 기능이 아직 구현되지 않았으면 버튼을 숨긴다. 새로고침은 서버 캐시 및 공급자 제한을 지킨다.
- 마크 가격/지수 가격/펀딩 비율/다음 펀딩은 디자인 참고로만 별도 4열 요약 영역을 예약한다. 데이터 기능 확정 전에는 숨기고, 확정 후에도 현물·ETF에 무관한 선물 값을 잘못 연결하지 않는다.

#### 4.3.4 데이터 계약 및 상태 처리

출처: [Binance 롱숏 상세](../indicator-collection/Binance_Metals_LongShort_20261123.md), [기능 명세 FR-108](../function/specification.md).

- 현재 수집 대상은 BTCUSDT 선물 및 XAUUSDT, XAGUSDT, COPPERUSDT, CLUSDT, BZUSDT의 4종 통계(24개 시계열)다.
- UI 키: provider + futures_symbol + ratioKind + period. 필수 필드: source_event_at, received_at, quality_status, long_pct/short_pct 또는 buy_pct/sell_pct. 원본 필드와 정의를 별도 유지한다.
- 계정/포지션 비율은 공급자의 유효한 longAccount/shortAccount 등 구성 비율을 백분율로 변환한다. longShortRatio만 존재하고 해당 정의가 확인된 경우, r = long/short로 두어 longPct = 100 × r/(1+r), shortPct = 100/(1+r). Taker buyVol/sellVol은 합이 양수인 경우 각 거래량/합 × 100으로 계산한다. 필드 간 정합성 오류·음수·비유한 값·분모 0은 결측/검수 처리한다.
- 비율은 내부 정밀도를 유지하고 화면에서는 소수점 1자리. 표시값의 반올림으로 합이 100%에서 벗어나지 않도록 한쪽의 표시값으로 다른 쪽의 보수를 구한다(검증된 원본에 한함). 막대는 유효 원본 비율을 사용한다.
- 기본 조회 300초, 공식 최소 집계 5분. WS 틱 또는 1초 스냅샷을 공식 롱·숏 비율로 간주하지 않는다. 새 timestamp가 없으면 기존 관측값과 원본 시각 유지. stale 상태는 명시하고 50/50 또는 0/0을 임의 생성하지 않는다.
- 집계 기준 전환 시 이전 기준 수치를 새 레이블로 잠시 노출하지 않도록 캐시 키를 분리한다.

### 4.4 매수·매도 Workflow 편집기 (승인 확정)

[Workflow 기능 및 실행 명세](../function/trading-workflow.md). 기존 금융 대시보드 디자인 토큰을 재사용하며, Workflow 화면은 ComfyUI/n8n에서 영감을 받은 노드 중심 편집 화면으로 구성한다.

| 영역 | 적용 구성 |
|---|---|
| 상단 툴바 | Workflow 이름, 버전, 저장, 검증, 모의 실행, 실행/중단, 실행 모드 |
| 좌측 라이브러리 | 시작, 데이터, 주식 그룹, 조건, 상태형 트리거, AND/OR/NOT/N-of-M 등 논리, 제어, BUY/SELL, 위험/알림/승인 블록; 검색 |
| 중앙 캔버스 | 드래그 배치, 방향성 연결선과 입력/출력 포트, 확대·축소, 팬 |
| 우측 설정 패널 | 지표·종목·비교식·임계값·기준가·집계 기간, 입력 검증 |
| 하단 실행 로그 | 노드별 충족/대기/오류/중단, 기준값·평가 시각·주문 상태 |

중단 노드는 별도 감시 경로와 시각적으로 구별한다. 조건 충족, 오류, 대기 및 중단은 색상 외 상태 문자·아이콘을 함께 표시한다. 포트 타입 오류와 무제한 순환은 검증에서 차단한다. LIVE 실행은 명시적인 모드 표시 및 사용자 확인을 요구하며 단순 편집으로 실주문이 활성화되지 않는다. 저장/모의 실행/디버깅/버전 관리 등 모든 승인 상세 기능은 Workflow 명세를 따른다. 노드 미니맵, 정렬/스냅, 다중 선택, 복사/붙여넣기, Undo/Redo 및 타입화된 포트, 변수/서브워크플로, 템플릿, JSON 가져오기/내보내기, 모의/백테스트/실주문 모드 및 승인·알림·성과 리포트 화면을 지원한다. 모바일은 실행 상태 조회를 우선하며 편집 지원 범위는 별도 확정한다.

#### 4.4.1 조건 분기 및 Workflow 재사용 디자인

- 조건 블록 오른쪽에 TRUE(충족), FALSE(미충족), UNKNOWN(확인 불가) 포트를 개별 표시한다. 연결선에 분기명과 방향을 표시하고 실행 중 선택된 선을 강조한다. 미선택 분기는 낮은 대비의 선 및 SKIPPED 문구로 표현한다. Switch, Fork, Join은 전용 노드 형태 및 포트를 사용한다.
- 노드 라이브러리에 '기존 Workflow' 분류를 추가한다. 검색 및 선택한 Workflow를 하나의 조건 카드로 드래그한다. 카드에는 Workflow 이름, 버전, 참조 아이콘, 현재 조건 결과, 하위 충족 수를 표시하고 펼치기/상세 이동으로 내부 그래프를 조회한다. 원본 그래프를 복제하지 않는다.
- 우측 설정에서 입력 매핑, 참조 버전, 결과 포트, 시간 제한을 설정한다. 순환 참조 또는 부작용 의존 조건의 검증 실패는 사유와 함께 표시한다.
- 상세/목록의 의존성 영역에서 '사용 중인 Workflow'와 '이 Workflow를 사용하는 Workflow'를 보여준다. 참조 중인 대상의 삭제 버튼은 비활성화하고 잠금 아이콘·참조 건수·사용하는 Workflow 링크를 표시한다. 해제/교체 후 다시 삭제할 수 있다. 강제 삭제 기능은 제공하지 않는다.

#### 4.4.2 메인 활성 개수 및 Workflow 상세 모니터링

메인 대시보드의 상단 상태 카드/헤더에 '활성 Workflow N개'를 표시하고 선택 시 활성 목록으로 이동한다. LIVE/PAPER/DRY_RUN별 수를 별도 표기하고 서버 집계값을 사용한다. 중복 실행 및 하위 호출은 총 활성 정의 수에 중복 포함하지 않는다.

```text
메인 대시보드
[활성 Workflow 3개]  [LIVE 1 / PAPER 2 / DRY_RUN 0] (예시)

Workflow 상세
[전략 이름] [v3] [PAPER] [감시 중] [실행 선택]
[충족 2/4] [미충족 1] [확인 불가 0] [미선택 1]
[조건 A ✓] ─ TRUE ─ [참조 Workflow B ✓] ─ [조건 C 감시]
          └ FALSE ─ [조건 D 미선택]
[현재값 / 기준값 / 마지막 평가 / 원본 시각 / 사유]
[실행 로그 및 실제 경로]
```

- 목록 및 상세의 상태는 선택 실행 기준. 활성 실행이 없으면 미실행/종료된 최신 이력이라고 명시한다.
- 충족은 녹색 체크, 미충족은 중립/미충족 문자, UNKNOWN은 경고 색상 및 사유, 감시는 강조 테두리, 미평가·미선택은 낮은 대비, 오류·중단은 경고 아이콘과 상태명으로 표현한다. 금융 상승/하락 색상과 조건 의미를 혼동하지 않는다.
- 순차 조건의 과거 충족 이력과 현재 평가 결과를 구분한다. 하위 Workflow는 부모 충족 집계에서 하나의 블록으로 세고 내부 진행도는 펼쳐서 보여준다. 분기별 진행 요약을 별도 제공하며 충족 비율은 주문 가능성으로 해석하지 않는다.
- 서버 스냅샷 및 상태 이벤트로 변경된 노드/카운트만 갱신한다. 접속 지연·끊김은 마지막 갱신 시각 및 상태로 명시한다. 모바일에서도 활성 수·상태·조건 목록을 조회할 수 있어야 한다.

#### 4.4.3 조건 유지 및 영업일 리셋 설정

조건 블록 선택 시 우측 설정 패널에서 '충족 유지 방식'을 선택한다. '달성 후 유지(LATCHED)'는 필요 달성 횟수(1 이상 정수) 및 유효 기한(다음 리셋까지/직접 기간 또는 만료 시각)을 표시한다. '실시간 유지(CONTINUOUS)'는 현재 참일 때만 충족되며 횟수 입력을 숨긴다. LEVEL/EDGE 등 기존 트리거 평가 방식과 별도 설정이다.

Workflow 상단 설정의 '조건 리셋 주기'는 당일(1영업일), 일주일(5영업일), 한 달(20영업일), 직접 입력(N영업일) 옵션과 기준 거래소 달력 선택을 제공한다. 현재 주기 시작/종료, 진행 영업일 수, 다음 리셋 시각 및 시간대를 표시한다. 저장은 새 버전으로 처리한다.

```text
조건 설정
충족 유지 방식  [달성 후 유지 ▾]
필요 달성 횟수  [ 3 ] 회
유효 기한       [다음 리셋까지 ▾]

Workflow 설정
조건 리셋 주기  [일주일 · 5영업일 ▾]
기준 달력       [미국 주식 거래소 ▾]
현재 주기       3/5 영업일 · 다음 리셋 [서버 계산 시각]

조건 상태 (예시)
A AND B           ✓ 충족
  A  3/3회 · 달성 후 유지 (현재 조건 FALSE)
  B  현재 TRUE · 실시간 유지
C OR D            ○ 미충족
```

대시보드에서 기존 AND/OR 연결식은 하나의 행으로 요약하고 내부 조건은 펼쳐 확인한다. 별도 그룹 생성 UI를 만들지 않는다. 래치로 유효 충족된 상태와 원본 현재값/품질을 분리하고, 만료/다음 리셋/횟수 및 미충족·UNKNOWN 사유를 표시한다. 서버가 리셋을 확정하기 전 브라우저가 임의로 상태를 초기화하지 않는다. 리셋은 주문 취소·보유량 청산·비상 중단 해제가 아니라 조건 상태 초기화라는 설명을 제공한다.

### 4.5 주식 그룹 관리 및 Workflow 노드

[주식 그룹 기능 명세](../function/stock-groups.md)의 승인된 집계 기능을 제공한다. 기존 다크/라이트 디자인 및 시세 카드 구조를 재사용한다.

- 그룹 목록: 이름, 태그, 전체/유효 구성종목 수, 그룹 평균 수익률을 크게 표시한다. 상승(빨강), 하락(파랑), 보합(회색) 100% 누적 막대와 각 종목 수·비율을 함께 표시한다. 롱숏 막대와 의미가 다르므로 명확히 구별한다.
- 그룹 상세: 구성종목 검색/추가/제거, 가중치 입력, 가격·수익률·신선도 표, 그룹 집계 차트, 기간·기준가·가중 방식 선택, 평균 상승/하락률·시장폭·변동 분산 및 비교 그룹. 저장·복제·버전 및 JSON 가져오기/내보내기.
- 그룹 노드: 라이브러리에서 StockGroup, GroupMetric, GroupCondition, GroupMemberCondition, GroupComparison, GroupInterrupt를 드래그한다. 우측 설정에서 그룹·버전·지표·기간·기준값·가중치·coverage·임계값을 선택한다.
- 실행 미리보기: 현재 값, 단위, 데이터 시각, 유효/전체 종목 수, 조건 결과, 그룹 버전, 제외 종목 및 사유. UNKNOWN/부분 집계/지연을 표시하고 결측을 0으로 표현하지 않는다.
- 실제 주문 대상과 그룹 신호를 별도 필드 및 연결로 표시한다. 그룹 편집 후 기존 실행은 고정 버전 유지.

### 4.6 금요일 종가매수 전용 대시보드 (승인)

| 예측 이력 | 대상 세션, 실제 관측 결과, 예측/모델 버전, 품질·검증 상태 |
| Workflow | 8종 예측 트리거 연결, 실행 모델 승인 및 데이터 품질 확인 |

예측 확률과 예측 신뢰도를 구분한다. 대상 월요일 날짜, 원본 및 피처 시각, 모델/데이터 버전, 표본 수를 표기한다. RESEARCH_EOD는 연구 전용으로 명확히 표시하고 실주문 연결을 비활성화한다. 미검증·결측·LOW_CONFIDENCE/ABSTAIN 등은 허위 확률을 채우지 않고 보류 사유를 표시한다. UI 샘플 숫자는 가상 데이터로 표시하고 실제 과거 사례로 위장하지 않는다. 모바일에서는 카드 세로 배치 및 테이블 스크롤을 지원한다.

## 5. 반응형 및 사용자 경험

원본의 실제 모바일 레이아웃 및 breakpoint는 미검증이므로 아래는 **Auto-Axe 구현 제안**이다.

| Viewport | 시세 카드 | 지표 카드 | 페이지 padding |
|---|---|---|---|
| ≥1200px | 4열 | 4열 | 30px |
| 900–1199px | 3열 | 2~3열 | 24px |
| 600–899px | 2열 | 2열 | 16px |
| <600px | 1~2열(최소 160px 및 실제 문구 폭 검증) | 1열 | 12px |

롱·숏 ON/OFF 전환 시 기존 그리드 열 수는 유지하고 동일 행 카드 높이를 일관되게 확장·복원한다. 좁은 화면에서는 집계 기준 드롭다운을 다음 줄로 이동시키며, 상세 3종 비율 패널은 900px 미만에서 2열, 600px 미만에서 1열을 기본 제안으로 한다. 세로 공간이 부족해도 양쪽 비율·집계 시각을 숨기지 않는다.

상세 컨테이너는 최대 960~1120px로 제한하고 좁은 화면에서 100% 폭으로 확장한다. 헤더 보조 설명을 축소하고 분류 탭을 가로 스크롤로 제공한다. 터치 타깃 최소 44px 권장, 키보드 포커스 표시, aria-label, 색상 외 방향 기호, 차트의 텍스트 요약 제공.

```css
.quote-grid {
  display: grid;
  grid-template-columns: repeat(4, minmax(0, 1fr));
  gap: 10px;
}
@media (max-width: 1199px) {
  .quote-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); }
}
@media (max-width: 899px) {
  .quote-grid { grid-template-columns: repeat(2, minmax(0, 1fr)); }
}
@media (max-width: 359px) {
  .quote-grid { grid-template-columns: minmax(0, 1fr); }
}
```

### 5.1 상태 및 갱신

| 상태 | 화면 표현 |
|---|---|
| fresh | 최신 수신 값·기준시각, 연결 상태 표시. 무지연을 단정하지 않음 |
| no_update | 최신 기존 값 유지 + 새 메시지 없음 |
| stale | 기존 값과 마지막 원본시각 + 지연 표시 |
| disconnected | 연결 끊김, 재연결 진행 상태 |
| no_data / missing | 대시 또는 데이터 없음, 0으로 대체 금지 |
| permission_required | 자동수집 비활성, 권한 확인 필요 |
| manual | 수동 입력, 입력/기준 시각 |
| session_reset | 누적량 리셋·거래일 변경 |
| loading | 카드 크기를 유지하는 skeleton |

1초마다 전체 페이지를 재렌더링하지 않는다. 수신 데이터와 화면 갱신을 분리해 필요한 카드만 갱신하며, 브라우저 숨김·오프라인에서 불필요한 UI 작업을 줄인다. 원본 관측 주기보다 짧게 새 데이터를 보여주는 허위 애니메이션을 사용하지 않는다. 카드 새로고침은 서버 캐시 및 호출 제한을 준수하며 무제한 외부 요청을 발생시키지 않는다.

## 6. 구현 및 검수

- 프론트엔드 프레임워크, 차트 라이브러리, CSS 기술은 확정하지 않는다. SVG 스파크라인 및 Canvas 기반 시계열 차트는 구현 후보이며 원본 라이브러리 사용 여부는 단정하지 않는다.
- 1차: 토큰·헤더·탭·카드·그리드·테마·샘플 데이터 기반 정적 프로토타입.
- 2차: 기존 기능 명세의 데이터 계약과 연결, 누락/지연/권한 상태 및 실제 시계열.
- 3차: 종목 상세 차트, 기술지표, 이벤트·거시 지표, 수집 상태.
- 4차: 반응형·키보드·대비·렌더링 성능 검수. 360/390/768/1024/1440px에서 잘림·오버플로 확인.
- 롱·숏 검수: OFF/ON 및 기준 변경, 전역 카드 동기화, 상세 3열/모바일 재배치, 0/100·50/50·75.8/24.2 테스트, 반올림 합 100%, 결측·미지원·stale, 집계 기간과 확인 주기 분리, Taker 레이블 및 현물/선물 상품 구분, 키보드 조작.
- 검수: 가격/단위/원본 시각 일관성, 상승/하락 색상과 텍스트, 탭 및 정렬, 1Hz 업데이트의 안정성, 차트 결측 처리, 라이트/다크 대비(일반 텍스트 WCAG AA 4.5:1 목표), 주문 관련 기능 비활성 상태 확인.

## 7. 근거 및 범위

- [원본 홈](https://live3x.com/): 화면 및 DOM, 카드/그리드 computed style, 테마 메뉴, 온도계 영역 확인.
- [원본 SOXL 상세](https://live3x.com/soxl): 출처 고지, 상세 헤더, 차트 조작부, 구성종목 필터·표 전환, 보조지표 확인.
